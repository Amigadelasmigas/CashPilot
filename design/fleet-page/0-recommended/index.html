Proxies

Copies of a service that leave through a proxy instead of the box's own connection. How it works

What is a copy?

ServiceLeaves throughExit IPProvider sees Originalearnfm→watchtower's own line→watchtower's own IP→device watchtower Copyearnfm→geiserct exit node (Tailscale)→203.0.113.71 · ES→device watchtower-p1
  • A copy is a second container of a service that already runs on a box.
  • Its traffic leaves through the proxy. The provider sees one more device on another IP, and pays it as one more device.
  • The original does not change. It keeps running on the box's own line.
  • If the proxy stops, the copy stops. It never uses the box's own IP.
  • Some providers forbid proxies. CashPilot refuses those services, or asks you to accept the risk first.
