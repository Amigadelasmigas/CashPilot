A copy is a second container of a service that already runs on a box. Its traffic leaves through the proxy, so the provider sees one more device on a different IP.

  • A service that uses the host's network, publishes ports, keeps data in a host folder or needs a GPU cannot run through a proxy. Each copy gets data volumes of its own.
