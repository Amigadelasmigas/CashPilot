Phones are not in the matrix: a phone cannot run copies. A copy runs on one box, so "from watchtower" names the box that runs it.

What is a copy?

  1. A copy is a second container of a service that already runs on a box.
  2. Its traffic leaves through a proxy, not through the box's own line.
  3. The provider sees a new device on a new IP. It pays for it as one more device.
  4. The original keeps running as before.
  5. If the proxy goes down, the copy stops. It never falls back to the box's own IP.

To start one, pick a + copy cell in a proxy's column. To manage a copy, pick its cell.

A copy has no value on an IP where the same service already runs. Some providers forbid proxies or VPNs. CashPilot asks you to accept that risk before it starts the copy.
