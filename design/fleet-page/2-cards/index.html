Proxies 1

Copies of a service that leave through a proxy instead of the box's own connection. How it works
What is a copy?
  • A copy is a second container of a service that already runs on a box. It uses the same image and the same account.
  • Its traffic leaves through a proxy. The provider sees a second device on a second IP address. It pays that device too.
  • The original does not change. It keeps running on the box's own connection.
  • It fails closed. If the proxy stops, the copy stops. It never sends from the box's own IP.
  • Some providers forbid proxies. CashPilot does not offer those services. For a service with an account risk, you must accept the risk first.
