How to turn on file mode, and how to undo it

Do it on each box. "Show steps" on a row gives the same steps for that box, and ticks each one as the box reports it.

  1. Add this line to the worker's environment 
    CASHPILOT_EARNER_SECRETS=file
    Show it in a compose file 
    services:
  cashpilot-worker:
    environment:
      - CASHPILOT_EARNER_SECRETS=file
  2. Recreate the worker container 
    docker compose up -d cashpilot-worker
  3. Redeploy each earner on that boxPress Redeploy on each one on the dashboard.

To undo: remove the line, then do steps 2 and 3 again. The passwords go back into the container settings.

What file mode protects against, and what it does not

docker inspect, a backup of Docker's folder and any tool with the Docker socket show the container settings in plain text. File mode takes the passwords out of them.

Root on that box can still read the file. File mode is not a wall against root.

It covers Bitping, Earn.fm, Honeygain, IPRoyal Pawns, ProxyBase, ProxyRack, Repocket, Traffmonetizer, URnetwork and Sia hostd. It does not cover custom services or Sia's wallet seed. Read the guide.

The socket proxy's policy is older than this worker (v3.1.0) needs, so some Docker calls may be refused. An image update never changes it: it lives in your compose file. curl -fsSL https://raw.githubusercontent.com/GeiserX/CashPilot/v3.1.0/docker-compose.yml | diff -u docker-compose.yml - > policy.diff
docker compose up -d cashpilot-socket-proxy

Or copy the lines from "# BEGIN socket proxy policy" to "# END socket proxy policy", and the CASHPILOT_PROXY_POLICY lines, from docker-compose.yml at v3.1.0
